# Single-A100 environment initialization

## Scope

The current phase targets one NVIDIA A100 40GB. It retains the real BAGEL
multimodal training path and studies CPU-GPU synchronization, H2D/D2H copies,
fused RMSNorm/RoPE/AdamW, token assembly, attention-mask construction, and MoT
expert execution. Multi-GPU communication is deferred.

The CUDA smoke test completed successfully with a BF16 4096 x 4096 matrix
multiplication on the A100. BAGEL's FlashAttention-dependent model modules also
imported successfully.

## Model strategy

The full BAGEL-7B-MoT EMA file is approximately 29.2 GB and is unsuitable for
single-GPU optimizer training once parameters, gradients, EMA, and AdamW state
are included. The first runnable baseline therefore uses the official
pretraining composition with a smaller language backbone:

- Qwen2.5-0.5B-Instruct
- SigLIP SO400M patch14-384 as the compatible public vision initialization
- BAGEL VAE (`ae.safetensors`)
- `Qwen2MoTDecoderLayer`, Flex Attention, frozen VAE

Weights and datasets live under ignored local directories and are never
committed. Exact launch arguments and compatibility/load diagnostics will be
recorded with the first baseline experiment.

## Known external issue
